# ¿Qué es Dopamine y Dopamine2 RootHide?

## Consideraciones?

# 1. Instalar el IPA

## Opción 1: Con Impactor

### 1. Descargar Dopamine o Dopamine2 RootHide

+ <a href="https://github.com/opa334/Dopamine/releases" target="_blank">Dopamine</a>
+ <a href="https://github.com/roothide/Dopamine2-roothide/releases" target="_blank">Dopamine Hide</a>

### 2. Instalar Impactor

+ <a href="https://impactor.claration.dev/" target="_blank">Impactor</a>
+ <a href="https://github.com/claration/Impactor" target="_blank">Impactor</a>

### 3. Ejecuta impactor

~~~bash
./app_image
~~~

### 4. Carga el IPA

1. Te pide tu Apple ID (Lo mejor es tener un Apple ID solo para pruebas de seguridad)
2. Al conectar el dispositivo debe aparecer tu iphone (Dale a trust)
3. Cargas el IPA 

# 2. Ejecutar el Jailbreak

## 1. Abre la aplicación Dopamine

1. Aparecerá la notificación "Untrusted Developer"
2. Settings => General => VPN & Device Management => Developer APP => Trust "email"
3. Developer Mode Required
4. Settings => Privacy & Security => Deveoper Mode (ON) => Restart
5. Tras el reinicio "Turn On"
6. Abres Dopamine y seleccionas Jailbreak
7. Instalas Sileo
8. Estableces un password para super usuario
